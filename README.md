📊 Google Ads Sales Analysis

📌 Project Overview

This project focuses on cleaning and analyzing Google Ads sales data using Python and Jupyter Notebook.

The main objective is to transform raw sales data into a clean, structured, and analysis-ready dataset.

⸻

📁 Project Structure

🧹 Data Cleaning

The data_cleaning folder contains:

* 📓 google_ads_sales.ipynb
    Jupyter Notebook containing the complete data cleaning and analysis process.
* 📄 GoogleAds_DataAnalytics_Sales_Uncleaned.csv
    Original Google Ads sales dataset used for the analysis.

⸻

🔍 Data Cleaning Process

The notebook covers the following steps:

* Loading and inspecting the dataset
* Understanding the dataset structure
* Checking data types
* Identifying missing values
* Checking for duplicate records
* Cleaning and preprocessing the data
* Performing data transformations
* Preparing the data for further analysis

⸻

🛠️ Tools & Technologies

* 🐍 Python
* 🐼 Pandas
* 🔢 NumPy
* 📓 Jupyter Notebook
* 📊 Data Analysis
* 🧹 Data Cleaning

⸻

🚀 How to Use

1. Open the data_cleaning folder.
2. Open google_ads_sales.ipynb.
3. Make sure GoogleAds_DataAnalytics_Sales_Uncleaned.csv is available in the same folder.
4. Run the notebook cells sequentially.
5. Review the data cleaning and analysis results.

⸻

🎯 Project Objective

The objective of this project is to demonstrate a practical data cleaning and analysis workflow using Python and prepare Google Ads sales data for further business analysis.
